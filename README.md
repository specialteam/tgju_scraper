# اسکریپر قیمت ارزهای TGJU

اسکریپر ساده و سبک برای دریافت قیمت ارزها از سایت [tgju.org](https://www.tgju.org/currency) با استفاده از `requests` و `BeautifulSoup`.

## ویژگی‌ها

- ✅ استفاده از `requests` برای دریافت صفحه (بدون نیاز به مرورگر)
- ✅ استفاده از `BeautifulSoup` برای پارس HTML
- ✅ شبیه‌سازی هدرهای مرورگر برای جلوگیری از بلاک شدن
- ✅ مصرف رم بسیار پایین (بدون Selenium)
- ✅ پشتیبانی از چندین روش پارس برای سازگاری بیشتر
- ✅ ذخیره نتایج در فایل JSON
- ✅ نمایش نتایج در کنسول

## نصب

1. ابتدا کتابخانه‌های مورد نیاز را نصب کنید:

```bash
pip install -r requirements.txt
```

یا به صورت دستی:

```bash
pip install requests beautifulsoup4 lxml
```

## استفاده

### اجرای ساده

```bash
python tgju_scraper.py
```

### استفاده در کد

```python
from tgju_scraper import TGJUScraper

# ایجاد نمونه از اسکریپر
scraper = TGJUScraper()

# دریافت قیمت ارزها
currencies = scraper.scrape()

# نمایش نتایج
scraper.print_currencies(currencies)

# ذخیره در فایل JSON
scraper.save_to_json(currencies, 'my_currencies.json')
```

## خروجی

اسکریپر نتایج را به صورت زیر نمایش می‌دهد:

```
============================================================
نام ارز               قیمت                 تغییرات            
============================================================
دلار آمریکا          42000                500               
یورو                 45000                300               
...
```

همچنین داده‌ها در فایل `currencies.json` ذخیره می‌شوند:

```json
[
  {
    "name": "دلار آمریکا",
    "price": "42000",
    "change": "500",
    "percent_change": "1.2%"
  },
  ...
]
```

## توضیحات فنی

### شبیه‌سازی مرورگر

اسکریپر با استفاده از هدرهای زیر مرورگر را شبیه‌سازی می‌کند:
- User-Agent: مرورگر Chrome
- Accept-Language: فارسی (fa-IR)
- سایر هدرهای استاندارد مرورگر

### روش‌های پارس

اسکریپر از چندین روش برای استخراج داده‌ها استفاده می‌کند:
1. جداول HTML (table)
2. div های با class های خاص
3. لینک‌های ارز
4. data attributes
5. لیست‌های ul/ol
6. داده‌های JSON درون اسکریپت‌ها

## عیب‌یابی

اگر داده‌ای پیدا نشد:
1. بررسی کنید که سایت در دسترس است
2. ممکن است ساختار سایت تغییر کرده باشد
3. در این صورت، HTML صفحه در فایل `page_source.html` ذخیره می‌شود تا بتوانید ساختار آن را بررسی کنید

## مشکلات احتمالی

### خطای Connection
- اتصال اینترنت خود را بررسی کنید
- ممکن است سایت موقتاً در دسترس نباشد

### داده‌ای پیدا نشد
- ساختار سایت ممکن است تغییر کرده باشد
- فایل `page_source.html` را بررسی کنید و کد پارس را به‌روز کنید
